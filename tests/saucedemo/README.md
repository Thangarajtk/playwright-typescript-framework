# SauceDemo Tests

Tests for the SauceDemo e-commerce application (https://www.saucedemo.com/).

## Test Files

- **visualcomparison.spec.ts** - Visual regression testing for the homepage
- **placeorder.spec.ts** - End-to-end order placement workflow

## What's tested

- User login functionality
- Product browsing and selection
- Shopping cart operations
- Checkout process
- Order confirmation

## Running tests

```bash
npm test -- tests/saucedemo
```
